# 📚 Library Management System

A full-stack Library Management System built to manage books, members, borrowing records, and library operations through a modern web interface.

## 🚀 Technologies

### Frontend
- React.js
- JavaScript
- HTML5
- CSS3
- Axios

### Backend
- ASP.NET Core
- C#
- Entity Framework Core
- RESTful API

### Database
- Microsoft SQL Server

## ✨ Features

- 📚 Manage books
- 👥 Manage library members
- 🔄 Manage borrowing and returning records
- 📊 Dashboard for library information
- 🔗 REST API communication between frontend and backend
- 🗄️ SQL Server database integration
- 📱 Responsive web interface
